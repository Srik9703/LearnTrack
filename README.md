# LearnTrack — Student & Course Management System

A console-based Core Java project for managing students, courses, and enrollments here data is held in memory and is reset when the application exits.
This system developed in Core Java. It allows admins to manage:

- Students (add, list, deactivate)
- Courses (add, list, activate/deactivate)
- Enrollments (enroll students in courses, view enrollments)

## Requirements
- JDK 7 or later.
- A terminal or Java IDE.

## Compile and run
- JDK 17 or above is installed and configured
- Open project in IntelliJ IDEA and navigate to src/com/airtribe/learntrack/Main.java.
- Find the main method. Select Run 'Main.main()'.

See [`docs/Setup_Instructions.md`](docs/Setup_Instructions.md)  for setup and Java runtime notes.
