# LearnTrack — Student & Course Management System

A console-based Core Java project for managing students, courses, and enrollments. Data is held in memory and is reset when the application exits.

## Requirements
- JDK 8 or later.
- A terminal or Java IDE.

## Compile and run
- Open project in IntelliJ IDEA and navigate to src/com/airtribe/learntrack/Main.java.
- Find the main method. Select Run 'Main.main()'.

See [`docs/Setup_Instructions.md`](docs/Setup_Instructions.md)  for setup and Java runtime notes.
